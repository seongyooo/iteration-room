# Iteration Room

**English** · [한국어](README.ko.md)

A first-person time-loop puzzle game in Unity, after the 2016 short film *Iteration 1*.

You wake in a bed in a sealed white facility. Sixty seconds later the loop takes you and you wake in
the same bed again — but the room remembers. Every previous run replays alongside you as a **ghost**:
a past self walking the exact path you walked, pressing what you pressed, carrying what you carried.
A door held open by a floor pad you cannot reach and stand at simultaneously becomes trivial once a
past self is standing on the pad. The whole game is that idea extended.

**Each iteration should leave you with less to do.** The building is one corridor of six rooms, and
finishing it means three puzzle rooms' worth of errands divided across as many past selves as it
takes.

Best measured clear: **iteration 10, in 4:47 total** (2026-08-14). A first run takes considerably
more.

## Running it

**Unity 6000.5.7f1** with URP 17.5.0. Do not change the Unity version — the render pipeline assets in
`Assets/Settings/` are wired against it.

```bash
git lfs install          # required: the furniture models are LFS objects
git clone <this repo>
```

**A fresh clone has no scenes.** `Assets/Scenes/*.unity` is git-ignored and regenerated — see
[Scenes are build output](#scenes-are-build-output). Open the project in Unity, then either:

- **In the Editor**: menu **`Iteration Room ▸ Build Whitebox Scene`**
- **Headless** (only when the Editor does *not* have the project open):

  ```bash
  Unity.exe -batchmode -nographics -projectPath . \
    -executeMethod IterationRoom.EditorTools.SceneBuilder.Build -quit -logFile build.log
  ```

The build writes both scenes, bakes seven reflection probes and captures the menu background. It
takes a couple of minutes. Look for `[SceneBuilder] IterationRoom scene built` and no `error CS` in
the log.

Then open `Assets/Scenes/MainMenu.unity` (build index 0) and press Play. `IterationRoom` is index 1.

> **Player Settings ▸ Run In Background must stay ON.** `Build()` sets it; the loop misbehaves
> without it.

## Controls

| | |
|---|---|
| **WASD** | Move |
| **Mouse** | Look |
| **Space** | Jump |
| **Left Shift** | Sprint |
| **Left Ctrl** | Crouch |
| **E** | Pick up · put down · operate (drawers, locks, recesses, plates) |
| **Left click** | Swing the pin at a balloon · place a chess piece |
| **N** | End the iteration early |
| **Esc** | Pause |

**E does one thing at a time.** Empty-handed it picks up whatever is nearest and on screen; with
something in hand it puts it down — unless you are standing at a fixture that wants what you are
holding, in which case it goes in. You carry **exactly one object**.

## The rooms

| | |
|---|---|
| **Calibration** | Mouse sensitivity, the control list, and a `BEGIN` plate. Before the clock. |
| **Room 1** | A bed, a nightstand, a floor pad and a door. Teaches the loop. |
| **Room 2** | A drawer, a pin, seventy balloons, three coloured keys. |
| **Room 2 West** | Twelve chess pieces scattered off a board. Put them back and the lights come up. |
| **Room 2 East** | Six glass cubes and six recesses that want them. |
| **Room 3** | Floor pads, a door, and a plinth. |
| **Room 4** | A console with three shaped recesses. **The only exit condition.** |

Each puzzle room pays out one escape object — a red cube, a blue sphere, a yellow triangle. All three
have to be in Room 4's console **within one iteration**, and nothing exempts them from the reset. The
clock runs through Room 4; reaching it ends nothing.

```
    Room/                   one puzzle's rule per file

    Audio/                  ambience and the PA announcer
  ArtAssets/                the only sourced content (CC models) — Git LFS
  Audio/                    generated by Tools/, not sourced
  Settings/                 URP pipeline assets
Tools/
  generate_sfx.py           every sound effect, standard library only
  generate_narration.ps1    45 announcer lines via Windows TTS
docs/                       why things are the way they are

TODO.md                     outstanding work
```

### Scenes are build output

`Assets/Scenes/*.unity` is generated by `SceneBuilder` and git-ignored. **Never edit a scene by
hand** — change `SceneBuilder.cs` and rebuild. Unity re-randomises every fileID on rebuild, so a
one-line script change produced an 11,000-line scene diff with no semantic content, and any merge of
two rebuilds was a guaranteed conflict over noise.

The scene `.meta` files **are** tracked: they pin the GUIDs that `EditorBuildSettings.asset` stores
by value.

### Almost everything is generated

Not just the scenes. The sound effects are synthesised by a Python script, the announcer is Windows
TTS, the wall grain is a generated normal map, every icon and symbol is drawn by code into a texture.
The only sourced content is `Assets/ArtAssets/` — a handful of Creative Commons models, whose exact
licences are tracked in `docs/asset-licences.md`. The bargain is that the
whole project rebuilds from scripts; to replace any generated asset with a real one, drop a file in
under the same name and delete nothing else.
